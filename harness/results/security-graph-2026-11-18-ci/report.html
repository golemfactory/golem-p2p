01. Inbound connection table (max_connections) can be filled by cheap valid handshakes that then stay idle; no per-source or per-identity cap

Module

Lenses

Sources

Reasoning

The excerpt shows the only established-connection bound is the global check at 1100. Records cost nothing to make (known limit), so in an open network one process can complete up to 1024 Hellos with self-signed records. If it keeps the connections alive with QUIC PINGs, honest inbound dials are refused. The known limit only covers the 128 pre-Hello slots for 10 s; post-handshake occupancy is new. Impact

Suggested fix

Impact
